这是博客的第一篇文章。

以后新增文章时，只需要在 `src/content/blog/` 目录下创建新的 Markdown 文件即可。

## 这套博客的工作流

1. 本地写 Markdown
2. 推送到 GitHub
3. 服务器拉取代码
4. 重新构建并部署

## 文件名和链接

当前文件名是 `hello-astro.md`，最终页面地址会是：

`/blog/hello-astro/`

后续你可以继续使用英文 slug 作为文件名，保持 URL 简洁稳定。
