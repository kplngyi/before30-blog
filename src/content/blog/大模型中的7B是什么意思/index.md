# 大模型中的 7B / 32B 是什么意思？

## 一、基本概念

在大语言模型（LLM）中，类似 **7B、13B、32B、70B** 的标识，表示：

> 👉 模型的参数规模（Parameter Count）

- **7B = 70亿参数（7 Billion）**
- **32B = 320亿参数**

这些参数是神经网络中的权重（weights）和偏置（bias），用于存储模型学到的知识。

---

## 二、参数的来源

大模型中的参数量是由各层神经网路中的权重矩阵和偏置项累加得到的，
在Transformer中主要来源于Embedding层、Attention层和前馈网络。

> Embedding 层

参数量 = vocab_size ✖️ hidden_size

> Attention 层
- 每一层Transformer都有QKVO(Output)
- 每个都是线性变换 hidden_size x hidden_size
- 参数量 = 4 x hiddens_size^2
> 前馈网络
- 参数量  ≈ 8 × hidden²

$$
W \leftarrow W - \eta \cdot \nabla_W L
$$

## 三、不同规模模型的能力对比

| 模型规模 | 能力特点 |
|--------|----------|
| 7B     | 基础对话、简单代码、轻量任务 |
| 13B    | 更稳定，理解能力提升 |
| 32B    | 复杂推理、较强泛化能力 |
| 70B    | 高级推理、接近专家水平 |

## 四、工程视角：资源消耗（重点）

### 显存需求（FP16）

| 模型 | 显存需求 |
|------|----------|
| 7B   | ~14GB |
| 13B  | ~26GB |
| 32B  | ~60GB+ |
| 70B  | ~140GB+ |

👉 结论：
- 单卡 3090（24GB） → 适合 7B / 勉强13B
- 32B → 必须多卡 / tensor parallel
- 70B → 分布式集群
